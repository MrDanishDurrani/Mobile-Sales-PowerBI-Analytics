# Mobile Sales Analysis Dashboard | Power BI
## Project Overview
This project is an interactive **Mobile Sales Analysis Dashboard** developed using **Microsoft Power BI**.
The dashboard analyzes mobile sales performance across different months, cities, mobile models, payment methods, and customer ratings.
It provides an interactive view of sales, quantity, transactions, customer ratings, and mobile model performance.
---
## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Analysis
---
## Project Objectives
- Analyze overall mobile sales performance
- Track total sales and total quantity
- Monitor total transactions
- Analyze sales by city
- Compare payment methods
- Analyze monthly quantity trends
- Analyze customer ratings
- Compare sales performance by mobile model
- Identify mobile models with higher sales and transaction volumes

## Geographic Analysis
The dashboard includes a map visualization showing **Total Sales by City**, allowing sales performance to be explored across different locations.
## Payment Method Analysis
Sales transactions are analyzed across different payment methods, including:
- UPI
- Debit Card
- Cash
- Credit Card
## Customer Rating Analysis
The dashboard analyzes customer ratings from **1 to 5**, helping identify the distribution of customer feedback.
## Mobile Model Analysis
The dashboard compares sales performance across mobile models.
Examples include:
- iPhone SE
- OnePlus Nord
- Galaxy Note 20
The analysis includes:
- Total Sales
- Total Quantity
- Transactions
